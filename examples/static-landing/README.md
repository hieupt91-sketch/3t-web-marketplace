# Fixture HTML nhập mẫu

Đây là gói minh họa hợp lệ cho adapter `static-html`, không phải frontend của nền tảng và không có backend/admin. Runtime nội dung chỉ tiếng Việt; metadata catalog có VI/EN để minh họa hai phạm vi locale khác nhau.

Nén **nội dung thư mục này** cùng manifest thành ZIP để dùng khi pipeline import đã được dev triển khai. Entry ở `site/index.html`, trang phụ `site/details.html`, CSS relative. Mở HTML trực tiếp chỉ kiểm tra nội dung fixture, không chứng minh hệ thống auto-demo đã tồn tại.

Không có secrets, dependencies bên ngoài, thanh toán hoặc email. Dùng source này làm fixture kiểm thử, không thay thế tài nguyên website thực tế của khách.
